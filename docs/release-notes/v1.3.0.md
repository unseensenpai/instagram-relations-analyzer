# v1.3.0 — 2026-11-25

Self-contained interactive HTML report export (with offline insights, triage checklist, dark/light theme, and re-import support).

## Added

### Interactive HTML Report Export (100% Offline)
Export any profile analysis, single list, or comparison diff as a single, self-contained `.html` file with zero external dependencies:

- **Profile Relations Dashboard:** Clickable KPI cards (Following, Followers, Mutual, Not Following Back, You Don't Follow Back), interactive SVG Donut chart, Reciprocity Rate, and Follower/Following Ratio.
- **Account Directory & Triage Mode:** Instant search, A–Z / Z–A sorting, **Cards ↔ Table** view switch, one-click **Copy Usernames**, direct **Open on Instagram** links, and a persistent **Mark Done / Hide Reviewed** checklist (saved in browser `localStorage`) so you can review accounts at your own pace.
- **Compare Diff HTML Report:** Exporting from the **Compare** tab generates a dedicated diff report with follower/following deltas, proportional change bar, and all 5 change categories including **Username Changed**.
- **Dark & Light Theme:** Built-in theme toggle remembered across sessions.
- **Re-importable HTML Snapshots:** Profile HTML reports embed the standard JSON snapshot inside `<script id="ig-relations-data" type="application/json">`, so you can load exported `.html` files directly back into the extension's **Compare** or **File Viewer** tabs.
- **Multilingual Reports:** Generated HTML reports automatically match the active extension language (English, Turkish, or Spanish).
