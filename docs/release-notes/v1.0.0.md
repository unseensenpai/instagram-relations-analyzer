# v1.0.0 — 2026-07-01

Initial release.

## Added

### Profile analysis
Fetches the followers and following lists of any Instagram profile you can
view — your own, any public profile, or a private one you follow — directly
from the browser using your existing session.

### Four relationship views
- **Following** — everyone the profile follows
- **Followers** — everyone who follows the profile
- **Not Following Back** — people they follow who don't follow back
- **You Don't Follow Back** — followers they haven't followed back

### Direct actions
Unfollow accounts or remove followers from within the panel. The local cache
and counters update immediately after each action.

### Local cache
Results are stored per profile in `localStorage`, so reopening a profile
loads instantly instead of refetching, and the last sync time is displayed.

### Data export
Download the currently open list as Excel-ready CSV (UTF-8 with BOM) or JSON,
or export the full profile dataset as a single JSON file with a summary
block.

## Notes

- A 1.5-second delay is applied between pagination requests to reduce the
  risk of hitting Instagram's rate limits.
- No data leaves the browser; requests go only to `instagram.com`.
