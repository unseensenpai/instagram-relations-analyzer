# v1.3.1 — 2026-11-25

Fixes Instagram pagination drift/duplicates that could misclassify mutual followers, adds incomplete-fetch warnings, and clarifies profile-relative relationship labels.

## Fixed

- **Instagram pagination drift & duplicate rows:** Switched `/api/v1/friendships/{id}/following/` and `/followers/` pagination from `count=50` to `count=200` and added `order=date_followed_latest` for `following` (with automatic HTTP 400 fallback). This eliminates unstable default-ranking page shifts that previously returned duplicate users and skipped accounts (causing mutuals to appear as non-mutuals).
- **Consistent deduplication:** Deduplicates fetched and cached `followers` / `following` lists by `pk` (fallback `username`) in both the extension panel and HTML reports so KPI totals always add up cleanly (`Following = Mutual + Not Following Back`, `Followers = Mutual + Not Followed Back`).
- **Partial/incomplete API response warnings:** Tracks expected profile totals vs. fetched unique counts and displays a clear warning banner in both the extension panel and exported HTML reports whenever Instagram's API returns partial or duplicated pages.
- **Profile-relative labels:** Replaced ambiguous first-person wording (*"You Don't Follow Back"* / *"Takip Etmiyorum"*) with clear target-profile labels (*"Not Followed Back"* / *"@{target} Doesn't Follow"* / *"@{target} Takip Etmiyor"*) so reports for other profiles are unambiguous.
