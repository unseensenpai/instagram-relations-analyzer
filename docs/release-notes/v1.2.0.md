# v1.2.0 — 2026-11-24

Snapshot comparison (JSON & CSV), browser-local sync history bar, offline file
visualizer, and major SPA/URL/cache reliability fixes.

## Added

### Compare Snapshots (JSON & CSV)
Compare your current profile relations against any previous **JSON** or **CSV**
export — or select **two files at once** (JSON+JSON, CSV+CSV, or JSON+CSV) to
compare them offline without even syncing a profile:

- **5 change categories:** New Followers, Lost Followers, New Following,
  Unfollowed, and **Username Changed** (detected via stable Instagram user IDs).
- **Visual change breakdown:** Summary banner with net follower/following
  deltas, proportional change bar, clickable filter chips, and a **Swap** button
  for two-file comparisons.
- **Direct actions in diffs:** Unfollow people who stopped following you
  directly from the Lost Followers list (if you still follow them).
- **Export diffs:** Download individual diff lists or a complete comparison
  report in CSV or JSON.
- Supports multi-section "Download All" CSVs (EN / TR / ES), semicolon-delimited
  Excel CSVs, and single-list followers/following CSVs.

### Browser-Local History Bar (IndexedDB)
Every successful sync is now automatically saved as a timestamped snapshot in
your browser's local **IndexedDB** (up to 20 snapshots per profile, with
automatic pruning). A compact **History** bar appears at the top of the panel so
you can pick any earlier sync and compare changes with one click — or delete old
snapshots directly. All data stays 100% local in your browser.

### Three Dedicated Panels & Minimizable Floating Trigger
The modal header now separates workflows into three clean tabs — **Profile
Analysis**, **Compare**, and **File Viewer** — so comparing external exports or
inspecting another profile's file never mixes with your active profile's lists.
The top-right **📊 IG Relations** floating button on Instagram can also be
collapsed into a compact edge icon (remembered across sessions).

### Offline Single-File Visualizer
Selecting a single JSON or CSV file when no profile cache is loaded opens it in
a read-only visualizer mode, letting you browse, search, and export all four
relationship lists directly in the panel.

## Fixed

### Wrong profile / stale cache shown after Instagram SPA navigation
Navigating between Instagram profiles does not reload the page, leaving older
SSR `<script>` tags in the DOM. Previously, `detectTargetProfile()` read the
first stale `profilePage_<id>` script tag, causing another profile's cached
analysis to appear under the new profile's title.

Profile IDs are now resolved authoritatively via Instagram's
`web_profile_info` endpoint (with session caching and username-verified DOM
fallback). Switching profiles clears stale UI immediately, cancels in-flight
syncs for the previous profile, and tracks URL changes live via `popstate` and
an active-panel watcher.

### Profile sub-URLs rejected as invalid
Profile subpages such as `/username/followers/`, `/username/following/`,
`/username/reels/`, and `/username/tagged/` are now recognized as valid profile
pages, while non-profile routes (`/p/...`, `/accounts/...`, `/direct/...`,
`/username/p/...`) are properly excluded.

### Other fixes
- **Followers tab action:** Fixed the Followers list showing *Unfollow* instead
  of *Remove* follower.
- **Sync cancellation:** Closing the panel while syncing now truly aborts
  in-flight requests and pagination timers via `AbortController`.
- **Accurate sync ETA:** Fixed progress ETA calculation dividing by cumulative
  count instead of average page size.
- **Search locale:** Search lowercasing now uses the active panel language
  instead of hardcoded Turkish (`tr`), fixing English/Spanish queries with `I`.
- **Consistent data & exports:** Users are slimmed immediately after fetch,
  `pk` values are normalized as strings, corrupted cache entries are handled
  safely, and CSV fields escape newlines and use explicit `\uFEFF` BOM.
